# guardtheory.net — search-demand research (2026-09-24)

**Method / evidence key.** No paid keyword tool. Volumes are triangulated from: (W) English-Wikipedia 2025 pageviews pulled live from the Wikimedia REST API (`wikimedia.org/api/rest_v1/metrics/pageviews/per-article/en.wikipedia/all-access/user/<Article>/monthly/2025010100/2025123100`) — verified; (AC) Google autocomplete pulled live from `suggestqueries.google.com/complete/search?client=firefox&q=…` — verified phrasing, no volume; (SR) Semrush public site overviews seen only in search snippets (direct fetch 404s) — reported, not verified; (GT) Google Trends as reported by https://br.submissionshark.com/blogs/shark-tank-bjj-studies-premium-content/fastest-growing-martial-arts (US, 2004–2024: BJJ +104.35%, judo −47.62%, wrestling still higher volume); (JJL) https://jiujitsulegacy.com/bjj-lifestyle/the-most-common-bjj-questions/ (claims "most asked on Google", method unstated); (EV) https://evolve-mma.com/blog/frequently-asked-questions-about-bjj/. YouTube per-video view counts could not be verified (youtube.com, Piped and Invidious all blocked the fetch); only channel-level figures are used.

**Tier definitions.** A = head term (Semrush-reported ≥100k/mo or Wikipedia ≥100k views/yr). B = Wikipedia 10k–100k/yr, or a dense autocomplete cluster. C = long tail; inferred from autocomplete/competitor coverage only (treat as unsourced estimate).
