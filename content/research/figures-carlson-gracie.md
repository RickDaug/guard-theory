## 2. Dates deliberately omitted

**No `lifespan` is set.** His individual fighter page on BJJ Heroes could not be retrieved today: `https://www.bjjheroes.com/bjj-fighters/carlson-gracie-sr` returned HTTP 403 (challenge page) on every attempt, and `carlson-gracie-jr` / `carlson-gracie-facts-and-bio` return 404. No second reachable source gave a birth or death date. The only sourced temporal fact is the year 2006 for his death, which appears in the entry body.

A widely circulated set of dates (13 August 1932 – 1 February 2006) exists, but the only place it was seen during this pass was a Wikipedia list page, which is not a source here. **If the fighter page becomes retrievable, add the dates and set `lifespan`.**
